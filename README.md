# drone-fc2-hw

Second-generation flight controller hardware (Altium), 2021: `flight-controller/`,
`power/` and `sensors/` boards. Schematic PDFs in `flight-controller/Docs` and
`sensors/Docs`.

Firmware repos targeting this board: [drone-model-based-kalman](https://github.com/Keyrim/drone-model-based-kalman),
[drone-driver-interface](https://github.com/Keyrim/drone-driver-interface),
[drone-throw](https://github.com/Keyrim/drone-throw).

History split out of drone-model-based-kalman (formerly drone-stm32f4-mark1) on 2026-10-20.
